# Getting help

Start with the [build guide](docs/GettingStarted.md),
[embedding guide](docs/Embedding.md), and
[browser example](examples/browser/README.md).

For reproducible bugs or feature proposals, open an
[issue](https://github.com/xndcn/dynarmic.js/issues). Include the commit, platform,
Node or browser version, Emscripten version, build options, command, and complete
error output. Guest failures also need the architecture and memory mode; a small
guest binary or saved fuzz case is especially useful.

This is a community-maintained project without a support SLA. Please keep
discussions respectful and focused on reproducible behavior. Report security
issues through [the security policy](SECURITY.md).
